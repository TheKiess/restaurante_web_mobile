# RFC-001 — Solicitação de mudança de requisito

> **A publicação de um RFC é opcional.** Se o professor decidir emitir uma solicitação de mudança, ele commita este arquivo preenchido no repositório do grupo e comunica a equipe pelos canais oficiais da turma. Enquanto a Seção 1 estiver em branco, nenhum RFC foi emitido e não há nada a preencher aqui.
>
> A **Seção 1** é preenchida pelo professor. As **Seções 2 e 3** são de responsabilidade do grupo.
>
> A mudança pode nascer em **qualquer um dos três componentes** — backend, cliente web ou app mobile. O pedido diz onde ela começa; a análise diz até onde ela vai. Preencha as subseções dos componentes afetados e registre explicitamente os que não foram, com a razão. Concluir que um componente não é afetado é uma conclusão legítima; deixar a subseção em branco não é.
